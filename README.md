# Polymer Glass Transition Lab · 玻璃化转变实验室

**浏览器内的实时粗粒化分子动力学。** 以 Kremer–Grest 珠簧模型演示聚合物的玻璃化转变：调节温度，观察链段动力学从扩散到笼效应、系统冻结成玻璃，并通过均方位移、弛豫时间发散、热历史与非高斯参数定位 Tg。

在线运行：**https://glory0707.github.io/polymer-glass-lab/**（GitHub Pages，无需安装）

## 功能

### 动力学与物理分析

- **实时分子动力学**：N ≤ 4800 珠，元胞列表邻居搜索，velocity-Verlet + Langevin 恒温，全部计算在浏览器 Worker 内完成
- **迁移率着色**：热成像色标（深钢蓝 = 冻结 → 冰白 → 琥珀 = 活跃），直接呈现动力学非均匀性
- **MSD–τ 双对数曲线**：扩散参考线；变更温度后历史曲线自动留存对比
- **弛豫时间 τp(T) 与 VFT 拟合**：MSD 穿越 1σ² 即 τα，降温扫描自动积累 log τp 对 1/T 数据，VFT 上弯（super-Arrhenius）与高温段 Arrhenius 直线对照——玻璃化最本质的定量图
- **自中间散射函数 Fs(q\*, τ)**：q\* = 6.7 σ⁻¹（主结构峰），两步弛豫（β 平台 → α 衰减），1/e 线给出 τα 的图解定义，中子散射实验的直接对应
- **热历史分析**：固定滞后窗口 MSD@20τ 与势能随温度变化，对数空间两段式拟合自动标注 Tg
- **非高斯参数 α₂(τ)**：量化动力学非高斯性（高斯过程为 0），原始 + 平滑双线
- **非均匀性视角**：邻域平滑迁移率的空间映射（χ₄ 视角）
- **van Hove 位移分布**：G_s(r, 5τ) 直方图 + 高斯参考，√ 纵轴揭示重尾

### 上手交互（实验台）

- **热笔**：点击/涂抹盒子任意位置注入局部热量，观察热扩散在玻璃态与液态中的反差
- **拽链探针**：抓住一根链拖着走，微观流变学式的黏弹性拖拽与回弹

### 结构与几何

- **切片视图**：双裁剪平面夹出 3.2σ 薄片并沿 z 拖动，露出内部的协同运动小岛
- **自由表面薄膜**：z 向换成软壁，层分辨迁移率剖面直接显示表面高速层——薄膜 Tg 下降（Keddie 效应）的微观起源
- **链刚度 κ 滑块**：柔性 → 半柔性链（U_bend = κ(1 − cosφ)）
- **双分散组分**：掺入 10–25% 小珠（σ = 0.7σ₀），演示增塑效应
- **密度调节**：0.6–1.3 σ⁻³ 准静态缩放；恒压（NPT）弱耦合压浴

### 力学与记忆

- **力学响应**：单轴拉伸（ε>2.5 自动回程）/ 循环拉伸，应力–应变实时曲线
- **键取向 P2 叠加**：Hermans 取向因子随应变的发展，与应力同图——应力光学（双折射）对应
- **记忆实验**：自定义温度阶梯协议（Kovacs 型），PE(t) 与 T(t) 同图展示路径依赖弛豫

### 包装

- **导览模式**：一键播放完整故事线（熔体 → 降温 → Tg 拐点 → 急冷 → 记忆实验），字幕解说
- **数据导出**：MSD、热历史、α₂、Fs(q,t)、τp(T)、应力、P2 一键导出 CSV / JSON
- **无头自检**：`npm run sanity`，25 项物理与数值检查（力梯度、NVE 守恒、恒温精度、玻璃化定性物理、Tg 拟合、VFT 还原、Fs 衰减/保持、P2 取向、热笔、拽链、薄膜壁约束与表面迁移率）

## 模型与方法

采用标准 Kremer–Grest 珠簧模型，LJ 约化单位（σ = ε = m = k_B = 1），周期性边界（薄膜模式下 z 向为对称软壁）。

| 相互作用 / 算法 | 形式 | 参数 |
|---|---|---|
| 非键合珠子 | WCA 排斥势（LJ 在 r_c = 2^(1/6)σ 截断并平移至零） | — |
| 链上相邻珠子 | FENE 键 | k = 30 ε/σ², R₀ = 1.5σ |
| 链刚度（可选） | U_bend = κ(1 − cosφ)，φ 为相邻键夹角 | κ = 0–10，滑块可调 |
| 组分（可选） | 双分散：掺入小珠 σ = 0.7σ₀ | 小珠占比 10% / 25% |
| 密度（可调） | 准静态盒缩放 | ρ = 0.6–1.3 σ⁻³ |
| 薄膜壁（可选） | z ∈ [2, Lz−2] 线性回复软壁 | k_wall = 150 ε/σ² |
| 恒温 | Langevin（velocity-Verlet + 每步一次 Ornstein–Uhlenbeck） | γ = 1.0 τ⁻¹，Δt = 0.008 τ |
| 体系 | 线形链，链长 40 | N = 1200 / 2400 / 4800，ρ = 1.0 σ⁻³ |

初始化为晶格随机游走链，构造后在 Δt/4 步长下短时退火消除重叠。

**Tg 的读出**：对固定滞后窗口 MSD@20τ(T) 在对数空间做两段式最小二乘拟合，两直线交点取为 Tg；τp(T) 的 VFT 拟合 T₀ 与之互为印证。Tg 依赖冷却速率（降温越慢越低），这是玻璃化的定义性特征，也是本演示可以亲手验证的现象。

## 本地运行

```bash
git clone https://github.com/Glory0707/polymer-glass-lab.git
cd polymer-glass-lab
npm run serve        # 静态服务器（python -m http.server 8000）
# 浏览器打开 http://localhost:8000
```

物理自检（Node，无需浏览器）：

```bash
npm run sanity
```

## 界面

- **底部温度轨**：拖动设定温度，轨道即色标，标出 Tg 邻域
- **左下控制簇**：降温 / 升温（连续扫描）、急冷 / 熔化（阶跃）、暂停；热笔 / 拖拽（上手工具，激活时接管指针）；⚙样品 打开规模、组分、几何（本体/薄膜）、速率、速度、链刚度、恒压、力学模式、珠色、键/框/串叠加与切片设置
- **右上读数**：温度（含实测）、势能、MSD、Tg 估计、模拟时长
- **「导览」**：一键播放完整实验故事线
- **「曲线」面板**：MSD–τ、弛豫时间 VFT、散射弛豫 Fs、热历史 + Tg、非高斯 α₂、van Hove、力学响应 + P2、（薄膜）层分辨剖面、记忆实验与数据导出
- 视口支持拖动旋转与滚轮缩放，空闲时缓慢环绕展示

## 精度与适用范围

定位为交互式演示与教学工具：体系尺度（N ~ 10³–10⁴）与冷却速率快于发表工作若干个量级，Tg 为操作定义（有限速率扫描下的拟合交点）。结构合理的定性结论（笼效应、非高斯性、VFT 上弯、表面高速层、Tg 随冷却速率的移动）可与文献对照；定量研究请在 LAMMPS / HOOMD 中复现平衡与退火协议。

## 实现说明

```
index.html          页面骨架 + importmap（Three.js 走 CDN，零构建）
src/md.js           MD 内核：WCA + FENE + 弯角势 + 薄膜软壁、热笔/拽链、Fs/P2/χ₄
src/sim.worker.js   Worker 宿主：模拟循环、采样（MSD/α₂/Fs/τp/热历史/剖面）与拟合
src/renderer.js     Three.js 渲染：InstancedMesh、切片裁剪平面、薄膜壁面、周期边界补画
src/plots.js        Canvas 图表：MSD、VFT、Fs、热历史、α₂、van Hove、力学+P2、剖面、记忆
src/analysis.js     温度分箱、两段式 Tg 拟合、τα 提取、VFT 拟合、色标
src/main.js         主循环、指针交互（热笔/拽链）、导览与 UI 接线
tools/sanity.mjs    无头物理自检（25 项）
```
