# 🧊 聚合物玻璃化转变实验室 / Polymer Glass Lab

**在浏览器里，亲眼看聚合物从液体冻成玻璃。**

一个周末玩具：Kremer–Grest 珠簧粗粒化模型的实时分子动力学，Three.js/WebGL 渲染几千个珠子，
一个温度滑块拖过去——链段从活蹦乱跳到冻进"笼子"，旁边的均方位移（MSD）曲线实时跟上，
**拐点就是玻璃化温度 Tg**。

> 灵感来自"客厅黑洞"系列：把一个严肃的物理模型做成放在客厅就能玩的可视化。
> 与聚合物物理模拟毕设同源，可当教学演示，也可当粗粒化 MD 的入门样本。

**▶ 在线运行**：`https://glory0707.github.io/polymer-glass-lab/`（GitHub Pages，无需安装）

## 怎么玩（30 秒版）

1. 打开页面，默认是 T=1.0 的高温熔体——珠子全红、MSD 顺着"斜率 1（扩散）"参考线爬。
2. 点 **「降温 ↓」**（或直接拖温度滑块），看珠子由红转蓝。
3. 温度掉到 **≈0.4 以下**：链段冻住，MSD 曲线压出一个**平台**（笼子效应），
   热历史图上白线（MSD@20τ vs T）出现拐点，两段式拟合自动标出 **Tg ≈ 0.4±0.1**。
4. 玩法挑战：
   - 换不同的降温速率，验证 **降得越慢，Tg 越低**（真实玻璃化的核心特征之一）；
   - 急冷 vs 熔化来回折腾，观察滞后；
   - 把珠色切成"按链分色"，看清每条链的构象。

## 物理模型（认真版）

LJ 约化单位（σ = ε = m = k_B = 1），三方向周期性边界：

| 相互作用 | 形式 | 参数 |
|---|---|---|
| 非键合珠子 | WCA 排斥势（LJ 在 r_c = 2^(1/6)σ 截断并平移至零） | 纯排斥，模拟良溶剂链段体积排除 |
| 链上相邻珠子 | FENE 键 | k = 30 ε/σ², R₀ = 1.5σ |
| 恒温 | Langevin（velocity-Verlet + 每步一次 Ornstein–Uhlenbeck） | γ = 1.0 τ⁻¹，Δt = 0.008 τ |
| 体系 | 单分散线形链 × 链长 40 | N = 1200/2400/4800，ρ = 1.0 σ⁻³ |

即标准 **Kremer–Grest 模型**（Grest & Kremer, JCP **86**, 4068 (1986); Kremer & Grest, JCP **92**, 5057 (1990)），
聚合物物理里最常用的粗粒化模型之一。

**为什么能看见 Tg：** 降温时链段松弛时间超指数增长（VFT 型），在有限的观察窗口内来不及松弛，
系统被冻结在过冷液体构型里——

- **MSD–τ（双对数）**：高温沿斜率 1 扩散；低温出现平台（链段被邻居困在"笼子"里），换温度自动存幽灵曲线对比；
- **热历史图**：固定滞后窗口 MSD@20τ 与每珠势能随 T 的曲线在玻璃化处弯折（后者即 DSC 的模拟类比）；
- **Tg 估计**：对 MSD@20τ(T) 做两段式最小二乘拟合，交点即拐点。真实体系 Tg 依赖冷却速率，本玩具同样如此——降温越慢，Tg 越低。

珠子颜色 = 近 5τ 迁移率（蓝=冻结 → 红=活跃），能直接看到玻璃态里稀疏的"局部活跃区"。

> ⚠️ 玩具级声明：N~10³、冷却速率比发表工作快若干个量级，用于定性直觉与教学；
> 定量结论（Tg 精确值、动力学非均匀性统计等）请用 LAMMPS/HOOMD 做正经模拟。

## 本地运行

需要任意静态服务器（ES module 不支持 file:// 直开）：

```bash
git clone https://github.com/Glory0707/polymer-glass-lab.git
cd polymer-glass-lab
npm run serve        # 或 python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

物理内核的 Node 无头自检（不需要浏览器，验证稳定性/恒温/玻璃化定性物理）：

```bash
npm run sanity       # = node tools/sanity.mjs
```

## 代码结构

```
index.html          页面骨架 + importmap（Three.js 走 CDN，零构建）
src/md.js           MD 内核：WCA+FENE、velocity-Verlet+Langevin、元胞列表（纯计算，Node 可复用）
src/renderer.js     Three.js 渲染：InstancedMesh 珠子 + 顶点着色键线 + 周期边界补画
src/plots.js        两块 Canvas 图表：MSD–τ 双对数、热历史/Tg
src/analysis.js     温度分箱、两段式拟合、颜色映射（纯函数）
src/main.js         主循环与 UI 接线
tools/sanity.mjs    无头物理自检
```

性能参考：N=2400 在普通笔记本浏览器上约 10–20 步/帧（60 fps 档），约 1 τ（LJ 时间）/秒；
用"速度"滑块可加速到 ~3 τ/秒。键长不发散、温度偏差可控、降温扫描拐点落在 T≈0.3–0.5，由 sanity 脚本保证。
