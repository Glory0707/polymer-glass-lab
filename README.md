# Polymer Glass Transition Lab · 玻璃化转变实验室

**浏览器内的实时粗粒化分子动力学。** 以 Kremer–Grest 珠簧模型演示聚合物的玻璃化转变：调节温度，观察链段动力学从扩散到笼效应、系统冻结成玻璃，并通过均方位移、热历史与非高斯参数定位 Tg。

在线运行：**https://glory0707.github.io/polymer-glass-lab/**（GitHub Pages，无需安装）

## 功能

- **实时分子动力学**：N ≤ 4800 珠，元胞列表邻居搜索，velocity-Verlet + Langevin 恒温，全部计算在浏览器内完成
- **迁移率着色**：热成像色标（深钢蓝 = 冻结 → 冰白 → 琥珀 = 活跃），直接呈现动力学非均匀性
- **MSD–τ 双对数曲线**：扩散参考线；变更温度后历史曲线自动留存对比
- **热历史分析**：固定滞后窗口 MSD@20τ 与势能随温度变化，对数空间两段式拟合自动标注 Tg
- **链刚度 κ 滑块**：柔性 → 半柔性链（U_bend = κ(1 − cosφ)），观察链形貌与 Tg 随刚度的变化
- **双分散组分**：掺入 10–25% 小珠（σ = 0.7σ₀），演示增塑效应与 Tg 调控
- **密度调节**：0.6–1.3 σ⁻³ 准静态缩放，观察堆积密度对玻璃化的影响
- **非高斯参数 α₂(τ)**：量化动力学非高斯性（高斯过程为 0）
- **非均匀性视角**：邻域平滑迁移率的空间映射，直接呈现动力学非均匀性（χ₄ 视角）
- **数据导出**：MSD 曲线、热历史、α₂ 一键导出 CSV / JSON
- **无头自检**：`npm run sanity`，15 项物理与数值检查（力梯度、NVE 守恒、恒温精度、玻璃化定性物理、Tg 拟合、双分散与密度稳定性）

## 模型与方法

采用标准 Kremer–Grest 珠簧模型，LJ 约化单位（σ = ε = m = k_B = 1），三方向周期性边界。

| 相互作用 / 算法 | 形式 | 参数 |
|---|---|---|
| 非键合珠子 | WCA 排斥势（LJ 在 r_c = 2^(1/6)σ 截断并平移至零） | — |
| 链上相邻珠子 | FENE 键 | k = 30 ε/σ², R₀ = 1.5σ |
| 链刚度（可选） | U_bend = κ(1 − cosφ)，φ 为相邻键夹角 | κ = 0–10，滑块可调 |
| 组分（可选） | 双分散：掺入小珠 σ = 0.7σ₀ | 小珠占比 10% / 25% |
| 密度（可调） | 准静态盒缩放 | ρ = 0.6–1.3 σ⁻³ |
| 恒温 | Langevin（velocity-Verlet + 每步一次 Ornstein–Uhlenbeck） | γ = 1.0 τ⁻¹，Δt = 0.008 τ |
| 体系 | 单分散线形链，链长 40 | N = 1200 / 2400 / 4800，ρ = 1.0 σ⁻³ |

初始化为晶格随机游走链，构造后在 Δt/4 步长下短时退火消除重叠。

**Tg 的读出**：对固定滞后窗口 MSD@20τ(T) 在对数空间做两段式最小二乘拟合，两直线交点取为 Tg。Tg 依赖冷却速率（降温越慢越低），这是玻璃化的定义性特征，也是本演示可以亲手验证的现象。

## 本地运行

```bash
git clone https://github.com/Glory0707/polymer-glass-lab.git
cd polymer-glass-lab
npm run serve        # 静态服务器（python -m http.server 8000）
# 浏览器打开 http://localhost:8000
```

物理自检（Node，无需浏览器）：

```bash
npm run sanity
```

## 界面

- **底部温度轨**：拖动设定温度，轨道即色标，标出 Tg 邻域
- **左下控制簇**：降温 / 升温（设定速率的连续扫描）、急冷 / 熔化（阶跃）、暂停；⚙样品 打开规模、速率、速度、链刚度、珠色与叠加元素设置
- **右上读数**：温度（含实测）、势能、MSD、Tg 估计、模拟时长
- **「曲线」**：呼出图 1（MSD–τ）、图 2（热历史）、图 3（非高斯参数 α₂）与数据导出
- 视口支持拖动旋转与滚轮缩放，空闲时缓慢环绕展示

## 精度与适用范围

定位为交互式演示与教学工具：体系尺度（N ~ 10³–10⁴）与冷却速率快于发表工作若干个量级，Tg 为操作定义（有限速率扫描下的拟合交点）。结构合理的定性结论（笼效应、非高斯性、Tg 随冷却速率的移动）可与文献对照；定量研究请在 LAMMPS / HOOMD 中复现平衡与退火协议。

```
tools/sanity.mjs    无头物理自检（数值梯度、NVE 守恒、降温扫描）
```
